# Contributing to water-report

Thanks for helping. Bug reports with a small input that shows the problem are the most useful contribution.

- Run `npm test` before opening a pull request. It builds the TypeScript and runs the tests in `test/`.
- Every change that alters a number or a limit needs a source (a standard, a paper or a published formula) in the pull request description. Results are used in engineering decisions, so values without a source are not merged.
- Sign off your commits (`git commit -s`). The sign-off says you wrote the change, or have the right to submit it, under the Apache License 2.0 that covers this project.
- Be kind. Disagree with the code, not the person.

Report security problems privately to contact@risprilabs.com rather than in a public issue.
